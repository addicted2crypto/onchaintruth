The default uses the Jan 5, 2024 BTC entry and the quote shown above. Alt loss is assumed. Editable inputs and other presets are scenarios. Bars compare endpoints, not a historical price path.

What this comparison measures

At entry, the same USD capital is used to buy either the alt or BTC. The BTC ending value uses the comparison BTC price; the alt ending value uses the assumed alt return. Alt value in BTC = ending alt USD value ÷ ending BTC price. BTC left behind = BTC bought at entry minus the alt’s ending BTC value. Each purchase in an actual wallet analysis needs its own entry date and BTC price. This scenario assumes a single purchase and excludes fees, taxes, and subsequent cash flows. Outperformance depends on the asset and dates.
